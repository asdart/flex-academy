# Flex Academy

Run from this workspace directory:

```sh
npm run dev
```

Open http://127.0.0.1:5173. Use the concept navigation to compare the three pages.

No dependency installation or build step is required. The existing website source is in `flex-concepts/dist/`.

- `/operator/`
- `/build-your-way-out/`
- `/business-school/`

Use `npm run dev -- --port 5174` to select another port. Run `npm run check` to check JavaScript syntax.

The registration and booking forms are design previews. They do not send data or create appointments.
